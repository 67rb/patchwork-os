# Patchwork personal desktop

A standalone, browser-based personal OS concept built with HTML, CSS, and JavaScript.

Open `index.html` in a browser. The desktop includes draggable windows, a live Johannesburg clock, an editable journal, and a small project workbench. Journal edits and new workbench ideas are saved in local browser storage.

The sample project cards reflect the Show Once and Goodhand prototypes in this workspace. The welcome and About copy is intentionally broad; update it in `index.html` to make the desktop sound more like you.
